# Engineering Rules

Never rewrite working architecture.

Never duplicate functionality.

Always extend existing modules.

Never create unnecessary files.

Always preserve TypeScript safety.

Never ignore compiler errors.

Never ignore lint errors.

Never guess APIs.

Always inspect the project before editing.

If an existing function can be extended, extend it.

Never create "v2", "new", "copy", or duplicate files.

---

# Coding Style

Prefer small functions.

Prefer composition.

Prefer server actions.

Keep business logic inside lib/.

Keep UI inside components/.

Keep pages thin.

---

# Before editing

Always inspect:

- imports
- exports
- interfaces
- types

Never break build.

Never break lint.

Never leave TODOs.

---

# Before finishing

Verify mentally:

✓ imports

✓ exports

✓ types

✓ build

✓ lint

If something is unclear,

ASK.

Do not invent code.
